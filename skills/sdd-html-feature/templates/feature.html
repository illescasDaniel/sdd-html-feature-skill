Where does validation happen?

Text equivalent: the endpoint checks access (step 2) before reading storage. Access failure exits as F1; an oversized report exits as F2 (not drawn; see the failures table). Neither path returns report data.

Explore an outcome

Success · permitted report

An authorized owner with a report within the limit receives a CSV download. Report data does not change.

F1 · access denied

Response 403 before any row is read. Copy: “You do not have access to export this report.” No download.

F2 · report too large

Response 422 with report_too_large. Copy: “This report is too large to export. Narrow the date range and try again.” No partial file.

Simulation: no backend is called. For UI features add realistic copy, every state (empty, loading, error, success) and a narrow layout here; for CLIs add transcripts and exit codes.

When they request an export,
